# rosbag 和 MCAP 学习计划

rosbag1、rosbag2 是 ROS 生态中的机器人数据录制体系，MCAP 是可承载多种消息编码的开放式容器格式。掌握它们的目的，是理解从采集、检查、解析到训练数据集化的完整链路，而不是机械地把所有文件互相改名。

---

### 📅 四周学习计划

整体思路：**先理清概念和命令行 → 再掌握编程读写 → 最后结合实战项目构建处理流**。

#### 第一周：概念与命令行快速上手
-   **目标**：搞清两种格式的定位，能用命令行完成录制、回放、查看。
-   **学习任务**
    1.  **rosbag**
        -   **rosbag1 (ROS 1)**：学习 `rosbag record`、`play`、`info` 命令。重点理解 `-a`、`-O`、`--split` 等常用选项。
        -   **rosbag2 (ROS 2)**：学习 `ros2 bag record`、`play`、`info`。重点理解 bag URI 目录、存储后端和 MCAP 插件；默认后端随发行版变化，不能写成所有环境都固定使用 SQLite3。
        -   实践：用 ROS 1/2 录制一小段话题数据，分别查看 `rosbag info` / `ros2 bag info` 的输出，了解消息数量、频率、时间范围。
    2.  **MCAP**
        -   理解 MCAP 的 schema、索引、压缩和定位读取能力；这些能力是否可用，取决于文件是否写入了对应记录。
        -   分别安装 MCAP Python SDK 和 MCAP CLI，然后用 `info`、`cat`、`filter`、`doctor` 检查一个现有 MCAP 文件。如果没有，可以从 [Foxglove 测试数据](https://github.com/foxglove/mcap/tree/main/tests/conformance/data) 里找。
-   **学习要点**：格式定位（rosbag 与 ROS 生态绑定，MCAP 是语言/平台无关的开放式容器格式）、命令行对比、文件结构感性认识。

#### 第二周：读取与理解数据
-   **目标**：能从 ROS 1 bag、rosbag2 bag URI 和独立 MCAP 中读取消息，分清话题、类型、编码和时间戳。
-   **重点**：`rosbags.AnyReader`、MCAP Python SDK、schema、message encoding、ROS 1/ROS 2 类型差异、`log_time` 与 `header.stamp`。
-   **产出**：一个只读检查脚本，输出文件类型、话题、消息数量、时间范围和消息类型；不修改原始文件。

#### 第三周：同步、清洗与数据集化
-   **目标**：把已解析的消息变成可分析、可训练的数据，并保留时间、单位、坐标系和质量信息。
-   **重点**：时间基准、最近邻匹配、缺帧处理、关节/动作表格化、Parquet、图像抽取、Foxglove 人工验收。
-   **产出**：一个小型 episode 数据集，包含状态、动作、图像索引、标签和质量报告。

#### 第四周：可复现的数据处理流水线
-   **目标**：把一次性脚本提升为可重复、可恢复、可审计的处理流程。
-   **重点**：原始数据不可覆盖、manifest、校验和、配置文件、幂等处理、失败重试、版本化 schema、批量统计。
-   **产出**：一个能够处理一批输入文件并生成派生数据、清单和质量报告的最小 ETL 原型。

#### 综合实战与高阶文章

-   **Foxglove 博客：Why We Use MCAP**

### 💡 直接可跑的学习起始代码

如果你希望直接动手，可以先用下面这两个极简示例感受差异，再按计划深入。

**1. 用 rosbags 读取一个 ROS 1 bag 或 rosbag2 bag URI**
```python
from rosbags.highlevel import AnyReader
from pathlib import Path

with AnyReader([Path('example.bag')]) as reader:
    # 打印所有话题
    for c in reader.connections:
        print(f"Topic: {c.topic}, Type: {c.msgtype}")
    # 反序列化为 Python 消息对象；需要字典时再自行转换
    for conn, ts, raw in reader.messages():
        msg = reader.deserialize(raw, conn.msgtype)
        # 你的处理逻辑放这里
```

**2. 用 mcap 库创建一个 MCAP 文件**
```python
import time

from mcap.writer import Writer
from mcap.records import Channel, Message, Schema

with open('sample.mcap', 'wb') as stream:
    writer = Writer(stream)
    writer.start(profile='', library='eai-learn-example')
    schema_id = writer.register_schema(
        Schema(
            name='example',
            encoding='jsonschema',
            data=b'{"type": "object"}',
        )
    )
    channel_id = writer.register_channel(
        Channel(
            topic='/example',
            schema_id=schema_id,
            message_encoding='json',
        )
    )
    timestamp_ns = time.time_ns()
    writer.add_message(
        Message(
            channel_id=channel_id,
            log_time=timestamp_ns,
            publish_time=timestamp_ns,
            data=b'{"msg": "hello"}',
        )
    )
    writer.finish()
```

按照这个计划，四周后你就能熟练驾驭两种格式，并为自己的数据处理系统打下坚实基础。如果在学习中遇到具体的技术细节，可以随时就某一点深入提问。
