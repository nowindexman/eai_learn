# 第二周：用 Python 读取并理解数据

第一周解决的是“文件能不能打开、命令会不会用”。第二周不急着转换格式，先建立一个只读的事实层：文件是什么、有哪些话题、消息类型是什么、消息字节如何解码、记录时间和传感器时间是否一致。

## 本周目标

- 用一个 Python 环境读取 ROS 1 `.bag` 和 ROS 2 bag URI。
- 用 `rosbags.AnyReader` 统一遍历消息，并能访问反序列化后的消息对象。
- 用 MCAP Python SDK 读取容器记录，区分 schema、channel、message 和 message encoding。
- 明确 `log_time`、`header.stamp`、`/clock` 和文件时间范围的区别。
- 产出一个只读检查脚本和一份检查结果；原始文件不被修改。

## 先记住三个边界

1. `rosbags` 返回的是生成的消息对象，不是天然的 Python 字典；要做 JSON/表格化，需要明确写转换逻辑。
2. MCAP 是容器，不是统一的消息语义。一个 `cdr` channel 仍需要对应 ROS 2 类型定义和解码器。
3. 读取器看到的记录时间通常来自 bag/MCAP 的日志时间，不必然等于消息内部的 `header.stamp`。

## 本周验收
