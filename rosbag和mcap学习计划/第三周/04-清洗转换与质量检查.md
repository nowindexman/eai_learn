# 04：清洗、转换与质量检查

## 1. 清洗的原则

清洗不是“把异常行删掉”。每个删除、填充、截断和单位换算都要能解释、统计和复现：

```text
原始消息 ──解析──> 规范化值 ──检查──> 标记异常 ──按策略派生──> 数据集
```

原始值、清洗后的值和异常原因应尽量分开保存。若必须丢弃，质量报告要记录数量、topic、时间范围和规则版本。

## 2. 最小质量指标

| 类别 | 指标 | 典型检查 |
|---|---|---|
| 完整性 | topic/消息/图像数量 | 与采集预期、频率和时长比较 |
| 时间 | 负跳变、重复、间隔异常 | 统计 delta、分位数、最大间隔 |
| 解码 | 反序列化/图像解码率 | 错误按 topic 和类型计数 |
| 结构 | 数组长度、字段范围、NaN | JointState 名称和数组对齐 |
| 语义 | 单位、坐标系、关节顺序 | 检查 manifest、TF 和标定 |
| 存储 | 文件大小、校验和、输出行数 | 防止输出截断或覆盖 |

“消息数量正确”只说明计数正常，不说明传感器内容正确；“能在 Foxglove 播放”也不能替代数值和语义检查。

## 3. 时间间隔检查

```python
import numpy as np


def timestamp_quality(time_ns: np.ndarray) -> dict[str, int | float]:
    if time_ns.ndim != 1:
        raise ValueError("time_ns must be one-dimensional")
    if len(time_ns) < 2:
        return {"count": int(len(time_ns)), "negative": 0, "duplicate": 0}

    delta = np.diff(time_ns.astype(np.int64, copy=False))
    positive = delta[delta > 0]
    return {
        "count": int(len(time_ns)),
        "negative": int((delta < 0).sum()),
        "duplicate": int((delta == 0).sum()),
        "min_positive_delta_ns": int(positive.min()) if len(positive) else 0,
        "max_delta_ns": int(delta.max()),
    }
```

不要把 `max_delta_ns` 直接当作“丢帧数”。若预期周期为 `period_ns`，可以估计异常间隔，但还要考虑发布抖动、录制暂停和时间戳来源。

## 4. JointState 检查

每条 `JointState` 至少检查：

```python
import numpy as np


def validate_joint_state(
    names: list[str] | tuple[str, ...],
    positions: list[float] | tuple[float, ...],
) -> list[str]:
    errors: list[str] = []
    if len(names) != len(positions):
        errors.append("name_position_length_mismatch")
    if len(set(names)) != len(names):
        errors.append("duplicate_joint_name")
    if any(name == "" for name in names):
        errors.append("empty_joint_name")
    if any(not np.isfinite(float(value)) for value in positions):
        errors.append("non_finite_position")
    return errors
```

关节角限制、速度限制和力矩限制必须来自机器人 URDF、控制器或采集协议，不能凭经验写一个“看起来合理”的通用阈值。若做单位转换（如度转弧度），要记录转换前后单位和规则版本。

## 5. 处理策略要可审计

推荐给每条派生行保留：

```text
is_valid
missing_image
decode_error
time_delta_ns
interpolation_method
cleaning_rule_version
```

不要在 Python 中直接 `dropna()` 后不统计行数。建议至少输出：输入行数、保留行数、删除行数、每个规则命中数、每个 topic 的错误数和最终质量等级。

## 6. 质量报告示例

```json
{
  "status": "warning",
  "source": "run_002",
  "metrics": {
    "state_rows_input": 10000,
    "state_rows_output": 9980,
    "image_match_rate": 0.997,
    "image_decode_rate": 0.999,
    "negative_timestamp_jumps": 0
  },
  "issues": [
    {
      "severity": "warning",
      "code": "image_gap",
      "count": 30,
      "policy": "keep_with_mask"
    }
  ]
}
```

`warning` 表示可以继续使用但必须知晓风险；`error` 表示不应进入训练数据；`info` 只记录观察，不影响状态。状态枚举和阈值要写进配置，不要散落在代码常量里。

## 7. 本篇练习

1. 对一个 episode 输出消息计数、频率、时间间隔、图像匹配率和解码率。
2. 造出一条数组长度不一致的 JointState，确认报告记录 error。
3. 对缺图像样本分别采用 drop 和 mask，比较样本数量和质量等级。
4. 把质量报告和 `state.parquet`、`images.parquet` 放在同一 episode 目录，并记录源文件校验和。

第三周结束时，你应能交付“可查询的数据 + 可解释的质量报告”，而不是只有一个看似成功的转换文件。
