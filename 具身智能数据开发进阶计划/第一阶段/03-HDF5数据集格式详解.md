# 03：HDF5 数据集格式详解

> HDF5 是机器人操作学习中最经典的训练数据格式。robomimic、DROID 早期版本和大量学术论文的数据集都以 HDF5 发布。它比 LeRobot 更简单直接——所有数据塞在一个文件里，用 NumPy 就能读写。本篇深入 robomimic 约定的标准结构，教你从零创建和验证一个 HDF5 数据集。

## 1. HDF5 基础（Web 工程师视角）

HDF5 是一种层次化数据格式，像文件系统一样组织数据：

| HDF5 概念 | 文件系统类比 | Web 类比 | 机器人数据中的角色 |
|-----------|------------|---------|------------------|
| File | 磁盘 | 数据库实例 | 一个 `.hdf5` 文件 |
| Group | 目录 | JSON 对象 | episode 分组、obs 分类 |
| Dataset | 文件 | 数组/表列 | 一个 numpy 数组（如 actions） |
| Attribute | 文件元数据 | 对象字段 | 帧数、单位、环境参数 |

```text
my_data.hdf5                    ← File
├── data/                       ← Group
│   ├── demo_0/                 ← Group（一个 episode）
│   │   ├── actions             ← Dataset (T, action_dim)
│   │   └── obs/                ← Group
│   │       ├── agentview_image ← Dataset (T, H, W, 3)
│   │       └── robot0_eef_pos  ← Dataset (T, 3)
│   └── demo_1/
│       └── ...
├── mask/                       ← Group（训练/验证分割）
└── [attrs]                     ← File 级属性（环境参数等）
```

### 为什么机器人领域偏爱 HDF5

1. **NumPy 原生**：Dataset 的底层就是 numpy 数组，零拷贝读写。
2. **多维数组友好**：关节状态 `(T, 14)`、图像 `(T, 720, 1280, 3)` 直接存，不用展平。
3. **单文件交付**：一个 episode 就是一个 `.hdf5`，方便分享和传输。
4. **随机访问**：`dataset[100]` 直接跳到第 100 帧，不用从头扫。
5. **压缩透明**：开启压缩后读写代码不变，自动透明压缩/解压。

### HDF5 的劣势

| 问题 | 说明 |
|------|------|
| **云存储差** | 单个大文件，S3 不支持 range read 时需要全量下载 |
| **并发写困难** | 多进程同时写一个文件需要 SWMR 模式或文件锁，易出错 |
| **不可流式** | 不像 Parquet 可以按列流式读，HDF5 需要打开整个文件 |
| **版本脆弱** | HDF5 库版本不匹配可能导致读取失败 |

> **务实建议**：如果你的团队用 robomimic 训练框架，HDF5 是默认格式。如果你从头搭建，LeRobot 的云原生特性更好。两者可以用工具互转。

## 2. robomimic HDF5 标准结构

robomimic 是斯坦福/UC Berkeley 开发的操作学习框架，它的 HDF5 约定已成为事实标准。大量后续工作（DROID、LIBERO 等）都沿用这个结构。

### 完整结构

```text
robomimic_dataset.hdf5
│
├── data/                                    ← Group：所有 episode 的根
│   │
│   ├── demo_0/                              ← Group：第 0 个 episode
│   │   ├── num_samples (attr: int)          ← 属性：该 episode 的帧数
│   │   ├── actions    (T, D_action)         ← Dataset：动作序列
│   │   ├── dones      (T,)                  ← Dataset：每步是否结束（最后一步为 True）
│   │   ├── rewards    (T,)                  ← Dataset：奖励（IL 中通常全 0）
│   │   └── obs/                             ← Group：所有观测
│   │       ├── agentview_image    (T,H,W,3) ← 第三人称相机
│   │       ├── robot0_eye_in_hand (T,H,W,3) ← 腕部相机
│   │       ├── robot0_eef_pos     (T, 3)    ← 末端执行器位置
│   │       ├── robot0_eef_quat    (T, 4)    ← 末端执行器姿态（四元数）
│   │       ├── robot0_gripper_qpos (T, 2)   ← 夹爪关节角
│   │       └── object             (T, D_obj) ← 物体状态（仿真中有，真机通常没有）
│   │
│   ├── demo_1/
│   │   └── ...（同上）
│   │
│   └── total (attr: int)                    ← 属性：总 episode 数
│
├── mask/                                    ← Group：训练/验证分割（可选）
│   ├── train_mask (N_total,)                ← Dataset：1=训练, 0=验证（按帧）
│   └── valid_mask (N_total,)                ← Dataset：1=验证, 0=训练
│
├── env_args (attr: str)                     ← File 属性：环境参数（JSON 字符串）
└── demo_id (attr on demo_X)                 ← 每个 demo 的属性：唯一标识
```

### 关键设计决策

| 决策 | robomimic 的选择 | 原因 |
|------|-----------------|------|
| 一个文件存什么 | 所有 episode 放一个文件 | 方便分割和批量加载 |
| 图像怎么存 | 压缩的 uint8 数组 | 保留无损像素，HDF5 透明压缩 |
| 动作维度 | 由机器人决定（7-DoF 单臂、14-DoF 双臂等） | 不做固定假设 |
| 训练/验证分割 | mask 数组按帧标记 | 灵活控制分割粒度 |
| 归一化统计 | **不存**在 HDF5 中 | robomimic 在代码中动态计算 |

> 注意最后一行：与 LeRobot 不同，robomimic 的 HDF5 **不包含 stats.json**。归一化统计量在训练代码中动态计算，通常在训练开始时遍历一次数据集算出来，然后缓存到 `experiment_dir/`。这是一个重要差异。

## 4. 命名约定

robomimic 的观测键命名有约定俗成的规则：

| 键名模式 | 含义 | 示例 |
|---------|------|------|
| `agentview_image` | 第三人称/外部相机 | 固定视角看桌面 |
| `robot0_eye_in_hand` | 腕部/眼在手内相机 | 看夹爪前方 |
| `robot{N}_eef_pos` | 第 N 个机器人的末端位置 | `(x, y, z)` |
| `robot{N}_eef_quat` | 第 N 个机器人的末端姿态 | `(x, y, z, w)` |
| `robot{N}_gripper_qpos` | 第 N 个机器人的夹爪关节角 | `(left_finger, right_finger)` |
| `robot{N}_joint_pos` | 第 N 个机器人的关节角 | 各关节弧度 |
| `object` | 物体状态（仿真） | 位置、姿态等 |
| `scene_rgb` | 场景 RGB 图像 | 同 `agentview_image` |

> 多机器人系统用 `robot0_`、`robot1_` 前缀区分。单臂系统通常省略数字。

### 完整创建脚本

```python
"""从已对齐的帧数据创建 robomimic 风格的 HDF5 数据集。"""
from __future__ import annotations

import json
from pathlib import Path

import h5py
import numpy as np


def create_robomimic_hdf5(
    output_path: Path,
    episodes: list[dict],
    env_args: dict,
    image_compression: str = "gzip",
) -> None:
    """创建一个 robomimic 风格的 HDF5 文件。

    Args:
        output_path: 输出文件路径
        episodes: episode 列表，每个 episode 是一个字典：
            {
                "actions": np.ndarray (T, D_action),
                "images": {
                    "agentview_image": np.ndarray (T, H, W, 3) uint8,
                    "robot0_eye_in_hand": np.ndarray (T, H, W, 3) uint8,
                },
                "states": {
                    "robot0_eef_pos": np.ndarray (T, 3),
                    "robot0_eef_quat": np.ndarray (T, 4),
                    "robot0_gripper_qpos": np.ndarray (T, 2),
                }
            }
        env_args: 环境元数据
        image_compression: 图像压缩算法
    """
    output_path.parent.mkdir(parents=True, exist_ok=True)

    with h5py.File(output_path, "w") as f:
        # File 级属性：环境参数
        f.attrs["env_args"] = json.dumps(env_args, ensure_ascii=False)
        f.attrs["format_version"] = "robomimic-1.0"

        data_group = f.create_group("data")
        data_group.attrs["total"] = len(episodes)

        all_frames: list[np.ndarray] = []  # 用于后续创建 mask

        for episode_idx, episode in enumerate(episodes):
            demo_key = f"demo_{episode_idx}"
            demo_group = data_group.create_group(demo_key)

            num_samples = len(episode["actions"])
            demo_group.attrs["num_samples"] = num_samples
            demo_group.attrs["demo_id"] = f"{env_args.get('env_name', 'demo')}_{episode_idx}"

            # 写 actions
            demo_group.create_dataset(
                "actions",
                data=episode["actions"].astype(np.float32),
            )

            # 写 dones（最后一步为 True）
            dones = np.zeros(num_samples, dtype=bool)
            dones[-1] = True
            demo_group.create_dataset("dones", data=dones)

            # 写 rewards（IL 中通常全 0）
            demo_group.create_dataset(
                "rewards",
                data=np.zeros(num_samples, dtype=np.float32),
            )

            # 写 obs group
            obs_group = demo_group.create_group("obs")

            # 写图像（带压缩）
            for image_key, image_data in episode.get("images", {}).items():
                obs_group.create_dataset(
                    image_key,
                    data=image_data.astype(np.uint8),
                    compression=image_compression,
                    compression_opts=4 if image_compression == "gzip" else None,
                    chunks=True,  # 启用分块，优化随机访问
                )

            # 写状态数据
            for state_key, state_data in episode.get("states", {}).items():
                obs_group.create_dataset(
                    state_key,
                    data=state_data.astype(np.float32),
                )

            all_frames.append(np.ones(num_samples, dtype=np.int8))

        # 创建训练/验证 mask（80/20 按 episode 分割）
        if "mask" not in f:
            mask_group = f.create_group("mask")
            total_frames = sum(len(mask) for mask in all_frames)
            train_mask = np.concatenate(all_frames)
            num_episodes = len(episodes)
            split_point = int(num_episodes * 0.8)

            # 前 80% episode 为训练集
            frame_idx = 0
            for episode_idx in range(num_episodes):
                ep_len = all_frames[episode_idx].sum()
                if episode_idx >= split_point:
                    train_mask[frame_idx:frame_idx + ep_len] = 0
                frame_idx += ep_len

            mask_group.create_dataset("train_mask", data=train_mask)
            mask_group.create_dataset(
                "valid_mask",
                data=(1 - train_mask).astype(np.int8),
            )

    print(f"HDF5 数据集已创建: {output_path}")
    print(f"  Episodes: {len(episodes)}")
    print(f"  总帧数: {sum(len(ep['actions']) for ep in episodes)}")
```

## 6. 读取与验证

```python
"""验证 HDF5 数据集的结构和数据完整性。"""
from __future__ import annotations

import json
from pathlib import Path

import h5py
import numpy as np


def validate_hdf5(path: Path) -> dict:
    """检查 HDF5 数据集的结构完整性，返回验证报告。"""
    report = {
        "file": str(path),
        "valid": True,
        "episodes": [],
        "issues": [],
    }

    with h5py.File(path, "r") as f:
        # 检查必需的顶层结构
        if "data" not in f:
            report["valid"] = False
            report["issues"].append("缺少 data/ group")
            return report

        # 读取环境参数
        if "env_args" in f.attrs:
            env_args = json.loads(f.attrs["env_args"])
            report["env_args"] = env_args

        data_group = f["data"]
        demo_keys = sorted(data_group.keys(), key=lambda k: int(k.split("_")[1]))
        report["num_episodes"] = len(demo_keys)

        # 检查每个 episode
        for demo_key in demo_keys:
            demo = data_group[demo_key]
            ep_report: dict[str, object] = {"demo": demo_key}

            # 检查必需字段
            required = ["actions", "dones", "obs"]
            for field in required:
                if field not in demo:
                    report["issues"].append(f"{demo_key} 缺少 {field}")
                    report["valid"] = False

            num_samples = demo.attrs.get("num_samples", 0)
            ep_report["num_samples"] = num_samples

            # 检查 actions 维度一致性
            if "actions" in demo:
                actions = demo["actions"]
                ep_report["action_shape"] = str(actions.shape)
                if actions.shape[0] != num_samples:
                    report["issues"].append(
                        f"{demo_key}: actions 长度 {actions.shape[0]} "
                        f"!= num_samples {num_samples}"
                    )

            # 检查 obs keys
            if "obs" in demo:
                obs_keys = list(demo["obs"].keys())
                ep_report["obs_keys"] = obs_keys

                # 检查每个 obs 的帧数一致
                for key in obs_keys:
                    obs_ds = demo["obs"][key]
                    if obs_ds.shape[0] != num_samples:
                        report["issues"].append(
                            f"{demo_key}/obs/{key}: 帧数 {obs_ds.shape[0]} "
                            f"!= num_samples {num_samples}"
                        )

                # 检查图像 dtype
                image_keys = [k for k in obs_keys if "image" in k]
                for img_key in image_keys:
                    dtype = demo["obs"][img_key].dtype
                    if dtype != np.uint8:
                        report["issues"].append(
                            f"{demo_key}/obs/{img_key}: dtype={dtype}, "
                            f"期望 uint8"
                        )

                # 检查状态数据有无 NaN
                state_keys = [
                    k for k in obs_keys
                    if "image" not in k and demo["obs"][k].dtype.kind == "f"
                ]
                for state_key in state_keys:
                    data = demo["obs"][state_key][:]
                    if np.isnan(data).any():
                        nan_count = int(np.isnan(data).sum())
                        report["issues"].append(
                            f"{demo_key}/obs/{state_key}: "
                            f"包含 {nan_count} 个 NaN"
                        )

            report["episodes"].append(ep_report)

        # 检查 mask
        if "mask" in f:
            mask_keys = list(f["mask"].keys())
            report["mask_keys"] = mask_keys

    report["total_issues"] = len(report["issues"])
    return report


# 运行验证
report = validate_hdf5(Path("box_transfer_robomimic.hdf5"))
print(json.dumps(report, indent=2, ensure_ascii=False))
```

## 7. 压缩与分块策略

HDF5 的压缩和分块直接影响文件大小和读取速度。

### 压缩算法对比

| 算法 | 压缩率 | 压缩速度 | 解压速度 | 适用场景 |
|------|--------|---------|---------|---------|
| `gzip`（level 1-9） | 高 | 慢 | 中等 | 归档、长期存储 |
| `lzf` | 中 | 快 | 快 | 日常训练（速度优先） |
| `szip` | 中 | 快 | 快 | 有许可限制 |
| 不压缩 | 无 | 无 | 最快 | SSD 上快速实验 |

```python
# 图像：gzip level 4（体积和速度的平衡）
f.create_dataset(
    "obs/agentview_image",
    data=images,
    compression="gzip",
    compression_opts=4,
    chunks=True,
)

# 状态数据：lzf（状态数据量小，压缩收益有限，速度优先）
f.create_dataset(
    "obs/robot0_eef_pos",
    data=positions,
    compression="lzf",
)

# actions：不压缩（太小，压缩开销不值得）
f.create_dataset(
    "actions",
    data=actions,
)
```

### 分块（Chunking）

分块决定 HDF5 如何把大数据切成小块存储。合理的分块能让随机访问只读取需要的块，而不是整个数据集：

```python
# 自动分块（HDF5 自己决定块大小）
f.create_dataset("obs/image", data=images, chunks=True)

# 手动指定块大小（适合知道访问模式时）
# 每块 100 帧 × 完整图像
f.create_dataset(
    "obs/image",
    data=images,
    chunks=(100, images.shape[1], images.shape[2], images.shape[3]),
    compression="gzip",
)
```

> **Web 类比**：分块类似于数据库的 page size。太小的块会增加元数据开销，太大的块会降低随机访问效率。默认 `chunks=True` 通常够用。

## 8. 多相机数据：适配你的 Orbbec 采集

你的 `数据采集样本/` 有 5 路 Orbbec 相机。在 HDF5 中这样组织：

```python
def create_multi_camera_hdf5(
    output_path: Path,
    camera_names: list[str],
    camera_images: dict[str, np.ndarray],  # {cam_name: (T, H, W, 3)}
    actions: np.ndarray,
) -> None:
    """为多相机系统创建 robomimic 风格 HDF5。"""
    with h5py.File(output_path, "w") as f:
        demo = f.create_group("data/demo_0")
        T = len(actions)
        demo.attrs["num_samples"] = T

        demo.create_dataset("actions", data=actions.astype(np.float32))
        dones = np.zeros(T, dtype=bool)
        dones[-1] = True
        demo.create_dataset("dones", data=dones)

        obs = demo.create_group("obs")
        for cam_name in camera_names:
            obs.create_dataset(
                cam_name,
                data=camera_images[cam_name],
                compression="gzip",
                compression_opts=4,
                chunks=True,
            )

        f.attrs["env_args"] = json.dumps({
            "env_name": "MultiCameraStation",
            "cameras": camera_names,
            "num_cameras": len(camera_names),
        })


# 你的 Orbbec 数据对应的键名
ORBBEC_CAMERA_KEYS = [
    "primary_color",           # primary: Orbbec Gemini 335
```

## 9. HDF5 vs LeRobot：什么时候用哪个

| 维度 | HDF5 (robomimic) | LeRobot v3 |
|------|-----------------|------------|
| **训练框架** | robomimic、自研 | LeRobot SDK、ACT 官方 |
| **图像压缩** | gzip/lzf（无损） | H.264 MP4（有损） |
| **体积** | 大（无损图像） | 小（有损视频） |
| **云存储** | 差（单文件） | 好（多文件分离） |
| **流式加载** | 不支持 | HF Hub streaming |
| **归一化统计** | 不存储（代码动态计算） | 存 stats.json |
| **可视化** | 需要自己写工具 | HF Hub 内置可视化 |
| **学习曲线** | 低（NumPy 直接读写） | 中等 |
| **并发写入** | 困难（需要 SWMR） | 好（多文件） |

### 决策建议

```text
用 HDF5 如果你：
  ✓ 训练框架是 robomimic 或需要兼容学术论文数据集
  ✓ 数据在本地 NVMe，不需要云存储
  ✓ 图像质量要求高（无损）
  ✓ 快速原型，不想搞复杂的多文件结构

用 LeRobot 如果你：
  ✓ 训练框架是 LeRobot SDK 或 ACT
  ✓ 需要在 HuggingFace Hub 上发布或共享
  ✓ 数据量大，需要云存储和流式加载
  ✓ 需要多人协作和数据版本管理
```

## 10. 并发写入的正确做法

HDF5 默认不支持多进程同时写同一文件。如果你的 Ray 流水线需要并行写入，有两种方案：

### 方案 A：每进程写独立文件，最后合并

```python
# 每个 Ray worker 写一个临时文件
def process_episode_to_hdf5(episode_data, output_path):
    with h5py.File(output_path, "w") as f:
        # 写单个 episode
        ...

# 合并
def merge_hdf5_files(file_paths: list[Path], output: Path) -> None:
    with h5py.File(output, "w") as out_f:
        data_group = out_f.create_group("data")
        for idx, path in enumerate(file_paths):
            with h5py.File(path, "r") as in_f:
                in_f.copy("data/demo_0", data_group, name=f"demo_{idx}")
        data_group.attrs["total"] = len(file_paths)
```

### 方案 B：SWMR（Single Writer Multiple Reader）模式

```python
# 只有一个 writer，多个 reader 可以同时读
with h5py.File("dataset.hdf5", "a", libver="latest") as f:
    f.swmr_mode = True
    # 写入...
    f.flush()  # 让 reader 看到最新数据
```

> SWMR 只支持一个 writer。多 writer 仍然不安全，用方案 A。

## 11. 常见坑

### 坑 1：忘记 `[:]` 导致读取空数据

```python
# ❌ 拿到的是 dataset 引用，不是数据
image = f["data/demo_0/obs/agentview_image"]
print(image)  # <HDF5 dataset "agentview_image": ...>

# ✅ 加 [:] 才真正读取
image = f["data/demo_0/obs/agentview_image"][:]
print(image.shape)  # (500, 84, 84, 3)
```

### 坑 2：文件未正确关闭导致损坏

```python
# ❌ 忘记 close
f = h5py.File("data.hdf5", "w")
f.create_dataset("actions", data=actions)
# 进程崩溃 → 文件可能损坏

# ✅ 用 with 语句
with h5py.File("data.hdf5", "w") as f:
    f.create_dataset("actions", data=actions)
# 自动关闭，即使出错也安全
```

### 坑 3：图像通道顺序混淆

```python
# robomimic 约定图像是 (H, W, C) 且 C=RGB
# 但 cv2 读取的默认是 BGR
image_bgr = cv2.imread("frame.png")
image_rgb = cv2.cvtColor(image_bgr, cv2.COLOR_BGR2RGB)

# ✅ 写入前确保是 RGB
obs_group.create_dataset("agentview_image", data=image_rgb)
```

### 坑 4：动作和状态的单位/坐标系不一致

HDF5 不存储单位信息（不像 LeRobot 的 info.json 有 names 字段）。你必须用属性或外部文档记录：

```python
# 用属性记录单位
demo.attrs["action_unit"] = "radian"
demo.attrs["action_description"] = "joint_angles_7dof"
demo.attrs["eef_pos_frame"] = "world"
```
