# 第零阶段：给 Web 工程师的概念地基

> 你有 10 年 Web 开发经验，懂得 API、数据库、ETL、分布式系统。但机器人数据和 ML 训练有一些概念，在 Web 世界里找不到直接对应物。本阶段用你最熟悉的 Web 类比，把三个核心概念从零讲清楚，让你后续读第一到第三阶段时不会卡在术语上。
>
> **不需要跑代码，不需要装环境。纯概念，读完即可。**

---

## 为什么需要这个阶段

后续文档里有大量这样的句子：

> "ACT 的 action chunk 通常为 100 步，observation window 取最近 1 帧"

如果你不知道"为什么模型要看多帧、预测多步"，这句话只是一个定义，无法形成直觉。

又如：

> "header.stamp 来自传感器硬件时钟，log_time 来自录制器"

如果你没有分布式系统中"不同时钟源"的经验，这两个时间戳的区别就是一段需要背诵的文字，而不是一个可以推理的概念。

本阶段解决的就是这个"知其然不知其所以然"的问题。

- bag 文件和 Web 日志系统有什么本质相似和不同？
