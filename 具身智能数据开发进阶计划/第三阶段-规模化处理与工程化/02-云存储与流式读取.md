# 02：云存储与流式读取

> 当数据量从几十 GB 增长到几 TB，本地磁盘放不下，你需要把数据放到对象存储（S3 / OSS / GCS）。但机器人数据的一个特点是：单个文件可能很大（1GB+ 的 bag），你不想每次处理都把所有文件下载到本地。本篇讲怎么做到"不落地处理"。

## 1. 数据湖架构

一个典型的机器人数据数据湖：

```text
                       ┌─────────────────────────────────┐
                       │        对象存储 (S3/OSS)          │
                       │                                 │
  采集设备 ───上传──→  │  raw/                           │
                       │    ├── session_001/             │
                       │    │   ├── primary.bag (1.1GB)  │
                       │    │   ├── secondary_1.bag (1GB)│
                       │    │   └── manifest.json        │
                       │    └── session_002/             │
                       │                                 │
                       │  derived/                       │
                       │    ├── dataset-v1/              │
                       │    │   ├── data/*.parquet       │
                       │    │   └── videos/**/*.mp4      │
                       │    └── dataset-v2/              │
                       │                                 │
                       │  manifests/                     │
                       │  reports/                       │
                       └─────────────────────────────────┘
                                    ↕
                       ┌─────────────────────────────────┐
                       │      计算节点（Ray Cluster）      │
                       │                                 │
                       │  方案 A：流式读取（不落地）        │
                       │  方案 B：本地缓存（部分落地）      │
                       │  方案 C：全量下载（简单但慢）      │
                       └─────────────────────────────────┘
```

## 2. 对象存储基础（Web 工程师可跳过）

如果你做过 Web 开发，S3/OSS 的概念你已经在用了：

| 对象存储概念 | Web 类比 |
|------------|---------|
| Bucket | 顶层目录 / S3 等价物 |
| Key | 文件路径 |
| Object | 文件内容 + 元数据 |
| Presigned URL | 临时下载链接 |
| Lifecycle Policy | 自动归档/删除策略 |
| Multipart Upload | 分片上传（大文件） |

```python
# 使用 boto3 (AWS S3) 或 oss2 (阿里云 OSS)
import boto3

s3 = boto3.client("s3")

# 上传
s3.upload_file("data/raw/session_001.bag", "my-bucket", "raw/session_001.bag")

# 下载
s3.download_file("my-bucket", "raw/session_001.bag", "/tmp/session_001.bag")

# 流式读取（不下载到磁盘）
response = s3.get_object(Bucket="my-bucket", Key="raw/session_001.bag")
stream = response["Body"]  # 这是一个可读流
```

## 3. 流式读取 bag/MCAP

### MCAP 的流式优势

MCAP 格式从设计上就支持流式读取——你可以逐条读消息，不需要把整个文件加载到内存：

```python
"""从 S3 流式读取 MCAP 文件。"""
import boto3
from mcap.reader import make_reader


def read_mcap_from_s3(bucket: str, key: str) -> None:
    """从 S3 流式读取 MCAP，不落地到磁盘。"""
    s3 = boto3.client("s3")
    response = s3.get_object(Bucket=bucket, Key=key)
    stream = response["Body"]

    reader = make_reader(stream)
    for schema, channel, message in reader.iter_messages():
        print(f"topic={channel.topic}, log_time={message.log_time}")
        # 处理消息...
```

### rosbag 的处理

ROS bag 不是为流式设计的，通常需要先下载。但可以用 **FUSE/S3FS** 挂载为本地文件系统：

```bash
# 挂载 S3 bucket 到本地目录
s3fs my-bucket /mnt/s3data -o url=https://s3.amazonaws.com

# 之后像本地文件一样访问
ls /mnt/s3data/raw/
python inspect_rosbag.py /mnt/s3data/raw/session_001.bag
```

> **性能注意**：S3FS 适合随机读取小文件，不适合顺序读取大文件（如 1GB bag）。大文件处理建议先下载到本地 NVMe，处理完后删除。

### 分段下载策略

```python
def download_with_cache(
    bucket: str,
    key: str,
    cache_dir: Path,
    expected_sha256: str | None = None,
) -> Path:
    """下载文件到本地缓存，如果已存在且校验和匹配则跳过。"""
    cache_path = cache_dir / Path(key).name

    if cache_path.exists():
        if expected_sha256 is None:
            return cache_path  # 无校验要求，直接用缓存
        actual_sha = compute_sha256(cache_path)
        if actual_sha == expected_sha256:
            return cache_path  # 校验通过，用缓存
        # 校验不通过，重新下载
        cache_path.unlink()

    cache_path.parent.mkdir(parents=True, exist_ok=True)
    s3 = boto3.client("s3")
    s3.download_file(bucket, key, str(cache_path))
    return cache_path
```

## 4. Hugging Face Hub 流式加载

LeRobot 数据集天然支持 HF Hub 流式加载——训练时不需要下载完整数据集：

```python
from lerobot.common.datasets.lerobot_dataset import LeRobotDataset

# 方式 1：流式加载（不下载完整数据集）
dataset = LeRobotDataset(
    "lerobot/aloha_sim_insertion_human",
    streaming=True,        # ← 关键：流式模式
)

# 按需加载单条样本（只有这条样本的数据被传输）
sample = dataset[0]

# 方式 2：下载到本地再加载
dataset = LeRobotDataset(
    "lerobot/aloha_sim_insertion_human",
    streaming=False,       # 下载完整数据集
    root="~/data/lerobot",
)
```

### 上传数据集到 HF Hub

```python
from huggingface_hub import HfApi

api = HfApi()

# 创建数据集仓库
api.create_repo(
    repo_id="my-org/box-transfer-v1",
    repo_type="dataset",
)

# 上传整个目录
api.upload_folder(
    folder_path="box_transfer_v1/",
    repo_id="my-org/box-transfer-v1",
    repo_type="dataset",
)
```

> 流式加载对训练非常重要：如果数据集是 500GB，你不需要在每台训练机上都存一份完整副本。HF Hub 的 CDN 会缓存高频访问的分片。

## 5. 数据分片策略

### 按什么分片

| 维度 | 示例 | 适用场景 |
|------|------|---------|
| 按 episode | `shard-000{episode_id}.parquet` | 最常见，天然并行 |
| 按时间 | `shard-2026-08.bag` | 时序数据，按月/天 |
| 按机器人 | `robot-001/shard-000.parquet` | 多机器人系统 |
| 按任务 | `pick/shard-000.parquet` | 多任务数据集 |
| 按大小 | 每 1GB 一个分片 | 控制单文件大小 |

### 分片大小权衡

```text
太小（< 100MB）：
  + 并行度高
  + 单文件下载快
  - 文件数过多，元数据管理复杂
  - S3 请求成本高（按请求计费）

太大（> 5GB）：
  + 文件数少，管理简单
  + S3 请求成本低
  - 单文件处理时间长，容错差
  - 流式读取缓冲区大

推荐：500MB - 2GB 每个分片
```

### LeRobot 的分片方式

LeRobot 默认按 episode_chunk 分片：

```text
videos/
├── chunk-000/          ← episode 0-99
│   └── observation.images.head/
│       ├── episode_000000.mp4
│       └── ...
├── chunk-001/          ← episode 100-199
│   └── ...
```

每个 chunk 包含固定数量的 episode，便于按块流式加载。

## 6. 存储成本优化

机器人数据体积大，存储成本是实际问题：

| 策略 | 节省 | 代价 |
|------|------|------|
| 原始 bag 用 zstd 压缩 | 30-50% | 读取时需要解压 |
| 图像用 MP4（H.264）而非 JPEG 帧 | 10-50x | 有损编码 |
| 深度图用 LZ4 压缩（已编码为 Y16） | 40-60% | 解压开销小 |
| 派生数据集用 Parquet 压缩 | 50-70% | 查询时解码 |
| 冷数据用 S3 Glacier 归档 | 90% | 恢复需要小时级 |

```python
# 生命周期策略示例：原始数据 30 天后转入低频存储
lifecycle_config = {
    "Rules": [{
        "ID": "archive-old-raw-data",
        "Filter": {"Prefix": "raw/"},
        "Status": "Enabled",
        "Transitions": [
            {"Days": 30, "StorageClass": "STANDARD_IA"},     # 30天后转低频
            {"Days": 90, "StorageClass": "GLACIER"},          # 90天后归档
        ],
    }],
}
```

## 7. 完整的云端处理流水线

```python
"""从 S3 读取原始 bag，处理后在 S3 写入 LeRobot 数据集。"""
import json
from pathlib import Path

import boto3


def cloud_pipeline(
    s3_bucket: str,
    session_prefix: str,     # 如 "raw/session_001"
    output_prefix: str,      # 如 "derived/dataset-v1/session_001"
    cache_dir: Path,
    fps: int = 30,
) -> dict:
    """云端 episode 转换流水线。"""
    s3 = boto3.client("s3")
    cache_dir.mkdir(parents=True, exist_ok=True)

    # 1. 列出 session 中的所有文件
    objects = s3.list_objects_v2(
        Bucket=s3_bucket,
        Prefix=session_prefix,
    )
    files = [obj["Key"] for obj in objects.get("Contents", [])]

    # 2. 下载 manifest（小文件，直接下载）
    manifest_key = f"{session_prefix}/manifest.json"
    manifest_obj = s3.get_object(Bucket=s3_bucket, Key=manifest_key)
    manifest = json.loads(manifest_obj["Body"].read())

    # 3. 下载 bag 文件到本地缓存（大文件）
    bag_files = [f for f in files if f.endswith(".bag")]
    local_bags: list[Path] = []
    for bag_key in bag_files:
        local_path = download_with_cache(
            s3_bucket, bag_key, cache_dir,
        )
        local_bags.append(local_path)

    # 4. 处理（复用第一阶段的转换代码）
    frames = extract_and_align(local_bags[0], fps=fps)

    # 5. 写入 LeRobot 格式到本地临时目录
    temp_output = cache_dir / "output" / Path(session_prefix).name
    frames_to_lerobot(frames, temp_output, fps=fps)

    # 6. 上传结果到 S3
    for file_path in temp_output.rglob("*"):
        if file_path.is_file():
            relative = file_path.relative_to(temp_output)
            s3_key = f"{output_prefix}/{relative}"
            s3.upload_file(str(file_path), s3_bucket, s3_key)

    # 7. 清理本地缓存
    for bag in local_bags:
        bag.unlink(missing_ok=True)

    return {
        "session": Path(session_prefix).name,
        "frames": len(frames),
        "output_prefix": output_prefix,
    }
```
