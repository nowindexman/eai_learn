# 为 ROS 2 文档做贡献

ROS 2 文档是社区共同努力的成果。我们欢迎各种形式的贡献！

## 文档仓库

ROS 2 文档托管在 GitHub 上：[ros2/ros2_documentation](https://github.com/ros2/ros2_documentation)

## 贡献方式

### 修复错误

如果您发现文档中的错误（如拼写错误、过时的说明或不准确的描述），可以：

1. 在仓库中提交 issue 描述问题
2. 直接提交拉取请求修复问题

### 添加新内容

如果您想添加新的教程、操作指南或概念文档：

1. 先在 Discourse 或 issue 中讨论您的想法
2. 获得社区反馈后开始编写
3. 按照现有文档的风格和格式编写
4. 提交拉取请求

## 文档格式

- 文档使用 **reStructuredText（RST）** 或 **Markdown** 格式
- 代码示例应包含完整的上下文，使读者可以直接运行
- 图片应存储在仓库的 `_images` 目录中

## 构建文档

本地构建文档以验证您的更改：

```bash
# 安装依赖
pip install -r requirements.txt

# 构建
make html
```

## 风格指南

- 使用清晰的标题层次结构
- 每个页面应有明确的目的
- 包含实际可用的代码示例
- 使用一致的术语（参见术语表）
