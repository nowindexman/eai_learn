# ROS 构建农场

ROS 构建农场是一套自动化系统，用于编译、测试和分发 ROS 包。

## 概述

构建农场执行以下功能：

- **持续集成（CI）** — 对每个拉取请求进行编译和测试
- **发布构建** — 编译已发布的包并生成二进制包
- **文档构建** — 生成 API 文档
- **覆盖率报告** — 计算和报告测试覆盖率

## 构建农场类型

- **开发构建** — 从源码仓库的最新代码构建
- **发布构建** — 从已发布的标签构建
- **文档构建** — 生成 API 文档

## 查看构建状态

- 构建状态可在 http://build.ros2.org/ 查看
- 包状态页面可在 http://repo.ros2.org/ 查看

## 覆盖率运行

覆盖率运行使用 `lcov` 工具收集代码覆盖率数据。覆盖率报告可以在构建农场的报告中找到。

### 本地测量覆盖率（Ubuntu）

使用 `lcov` 工具在本地测量覆盖率：

```bash
# 安装 lcov
sudo apt install lcov

# 编译时启用覆盖率
colcon build --cmake-args -DCMAKE_BUILD_TYPE=Debug -DCMAKE_CXX_FLAGS="--coverage"

# 运行测试
colcon test

# 生成覆盖率报告
lcov --capture --directory build/ --output-file coverage.info
genhtml coverage.info --output-directory coverage_report
```
