# 代码风格和语言版本

为了实现一致的产品外观，我们都遵循外部（如果可能）定义的各种语言的风格指南。

## C

### 标准
目标：**C99**

### 风格
使用 [Python 的 PEP7](https://www.python.org/dev/peps/pep-0007/) 作为 C 风格指南，并做一些修改：
- 目标 C99（不需要支持 C89）
- 允许 C++ 风格的 `//` 注释
- （可选）始终将字面值放在比较运算符的左侧，如 `0 == ret`

## C++

### 标准
Jazzy 目标：**C++17**

### 风格
使用 [Google C++ 风格指南](https://google.github.io/styleguide/cppguide.html)，并做一些修改：

- **行长度**：最大 100 个字符
- **文件扩展名**：头文件使用 `.hpp`，实现文件使用 `.cpp`
- **变量命名**：全局变量使用小写加下划线，前缀 `g_`
- **函数和方法命名**：Google 风格指南要求 `CamelCase`，但也允许 C++ 标准库风格的 `snake_case`（因为 ROS 2 核心包目前使用 `snake_case`）

## Python

### 版本
目标：**Python 3**

### 风格
遵循 [PEP 8](https://www.python.org/dev/peps/pep-0008/) 风格指南。

## CMake

### 版本
目标：**CMake 3.5+**

### 风格
- 使用小写命令
- 缩进使用 2 个空格
- 参数之间使用空格分隔，不使用分号

## Markdown / reStructured Text / docblocks

### 通用规则
- 每行最大 100 个字符
- 使用描述性的标题和章节组织
