# 功能状态

以下列出的功能在当前 ROS 2 发行版中可用。除非另有说明，功能适用于所有支持的平台（Ubuntu 24.04 Noble、Windows 10）、DDS 实现（eProsima Fast DDS、RTI Connext DDS、Eclipse Cyclone DDS）和编程语言客户端库（C++ 和 Python）。

| 功能 | 说明 |
|---|---|
| **基于 DDS 的发现、传输和序列化** | ROS 2 通信基础 |
| **支持多种 DDS 实现**，运行时可选 | 当前完全支持 Eclipse Cyclone DDS、eProsima Fast DDS 和 RTI Connext DDS |
| **通用核心客户端库**，由语言特定库封装 | rclcpp (C++) 和 rclpy (Python) |
| **话题上的发布/订阅** | 核心通信模式 |
| **客户端和服务** | 请求/响应通信 |
| **设置/获取参数** | 运行时配置 |
| **ROS 1 - ROS 2 通信桥接** | 适用于话题和服务，动作尚不可用 |
| **QoS 设置处理非理想网络** | 服务质量配置 |
| **进程间和进程内通信使用相同 API** | 目前仅 C++ |
| **节点组件组合**（编译/链接/加载/运行时） | 目前仅 C++ |
| **同一节点中的多个执行器**（回调组级别） | 仅 C++ |
| **支持具有托管生命周期的节点** | 目前仅 C++ |
| **DDS 安全支持** | sros2 |
| **使用可扩展框架的命令行内省工具** | ros2 CLI |
| **Launch 系统协调多个节点** | 支持 XML/YAML/Python |
| **节点和话题的命名空间支持** | 命名和范围 |
| **ROS 名称的静态重映射** | 命令行参数 |
| **全 ROS 2 移动机器人演示** | turtlebot2_demo |
| **对实时代码的初步支持** | 仅 Linux |
| **对"裸金属"微控制器的初步支持** | micro-ROS |
| **内容过滤订阅** | 目前仅 C++ |
| **服务内省** | 服务监控 |

除了平台的核心功能外，ROS 的最大影响力来自其可用的软件包。以下是一些在当前版本中可用的高知名度包：

- **[gazebo_ros_pkgs](https://index.ros.org/r/gazebo_ros_pkgs/)** — Gazebo 仿真集成
- **[image_transport](https://index.ros.org/r/image_common)** — 图像传输
- **[navigation2](https://index.ros.org/r/navigation2/)** — 导航框架
- **[rosbag2](https://index.ros.org/r/rosbag2/)** — 数据录制和回放
- **[RQt](https://index.ros.org/r/rqt/)** — Qt 可视化工具
- **[RViz2](https://index.ros.org/r/rviz/)** — 3D 可视化工具
