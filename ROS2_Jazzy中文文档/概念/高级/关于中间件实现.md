# ROS 2 中间件实现

## 概述

ROS 中间件实现提供底层通信框架的包集合。这些包与 `rmw`、`rcl` 和 `rosidl` API 交互，集成 Zenoh、DDS 等外部协议。

## DDS 中间件实现的通用包

`rosidl_dds` 仓库中的 `rosidl_generator_dds_idl` 包：从 rosidl 文件生成 DDS `.idl` 文件，DDS 实现再用这些文件创建供应商特定的预编译类型支持。

## DDS 中间件实现的结构

典型的 DDS 中间件实现包含以下包：

- `<implementation_name>_cmake_module` — 发现和暴露所需依赖的 CMake 模块
- `rmw_<implementation_name>_<language>` — RMW API 实现（通常为 C++）
- `rosidl_typesupport_<implementation_name>_<language>` — 生成 rosidl 文件的静态类型支持代码

### 示例仓库
- Eclipse Cyclone DDS：`ros2/rmw_cyclonedds`
- Fast DDS：`ros2/rmw_fastrtps_cpp`
- Connext DDS：`ros2/rmw_connextdds`
- GurumDDS：`ros2/rmw_gurumdds`

## Zenoh 中间件实现的结构

`rmw_zenoh_cpp` 将 ROS 2 中间件 API 映射到 Zenoh API：

- **节点**：Zenoh 没有直接对应，创建时声明 `NN` 类型的活性令牌
- **发布者**：直接映射到 Zenoh Publisher，声明 `MP` 令牌
- **订阅者**：直接映射到 Zenoh Subscriber，声明 `MS` 令牌
- **服务客户端**：使用 Zenoh queryables，声明 `SC` 令牌
- **服务服务器**：使用 Zenoh queryables，声明 `SS` 令牌

每个 ROS 2 context 映射为单个 Zenoh 会话，需要 Zenoh 路由器（`zenohd`）在本地运行或可通过网络访问。

仓库：`ros2/rmw_zenoh`
