# 构建系统

## 概述

构建系统允许开发者按需构建 ROS 2 代码。ROS 2 重度依赖将代码分为包（package），每个包包含一个清单文件（`package.xml`），其中包含包的元数据和依赖信息。

ROS 2 构建系统由三大概念组成：

## 构建工具（Build Tool）

控制单个包编译和测试的软件。ROS 2 中通常 C++ 使用 CMake，Python 使用 setuptools，也支持其他构建工具。

## 构建辅助工具（Build Helpers）

挂载到构建工具上以改善开发者体验的辅助函数。ROS 2 包通常依赖 `ament` 系列包。

### ament_package
提供 ament 包的各种实用工具，如环境钩子模板。所有 ament 包必须在根目录包含 `package.xml` 文件。

### ament_cmake 仓库
包含提供 ament CMake 包基础设施的 CMake 函数/宏和模块：
- `ament_cmake` — 聚合所有其他包
- `ament_cmake_auto` — 自动处理 CMakeLists.txt 的便捷函数
- `ament_cmake_core` — 核心概念（环境钩子、资源索引、符号链接安装等）
- `ament_cmake_gmock/gtest` — 测试便捷函数
- `ament_cmake_python` — Python 代码包的 CMake 函数
- `ament_cmake_test` — 统一测试目标

### ament_lint 仓库
提供代码检查和测试服务：uncrustify（C++风格）、cppcheck（静态检查）、pep8（Python 风格）等。

## 元构建工具（Meta-build Tool）

知道如何对一组包进行拓扑排序并按依赖顺序构建或测试。ROS 2 中使用 [colcon](https://colcon.readthedocs.io/en/released/)。
