# 中级概念

这些概念进一步深化对基本 ROS 2 系统的理解。

## 主题列表

- **[ROS_DOMAIN_ID](关于域ID.md)** — 域 ID 控制节点之间的通信范围。默认情况下，同一网络上的所有节点使用相同的域 ID（通常为 0），因此可以相互发现并通信。通过设置不同的 `ROS_DOMAIN_ID` 环境变量，可以在同一网络上隔离不同的节点组。

- **[不同的 ROS 2 中间件供应商](关于不同中间件供应商.md)** — ROS 2 支持多种 DDS 中间件实现（如 Fast DDS、Cyclone DDS、Connext DDS），可以在运行时选择。不同的中间件可能在性能、功能和支持平台方面有所差异。

- **[日志和日志器配置](关于日志.md)** — ROS 2 提供了灵活的日志系统，支持多个日志级别（DEBUG、INFO、WARN、ERROR、FATAL），可以通过环境变量或 API 在运行时配置。

- **[服务质量（QoS）设置](关于QoS.md)** — QoS 策略允许您微调节点之间的通信行为，包括可靠性、持久性、历史深度等设置。正确的 QoS 配置对于在非理想网络条件下确保可靠通信至关重要。

- **[执行器](关于执行器.md)** — 执行器控制回调的执行方式。ROS 2 提供了多种执行器类型，包括单线程和多线程执行器，以满足不同的并发需求。

- **[话题统计](关于话题统计.md)** — 话题统计提供关于消息传递性能的内置测量，包括消息年龄和消息周期。

- **[RQt 概述和使用](关于RQt.md)** — RQt 是一个基于 Qt 的图形化框架，提供了多种用于系统监控和调试的可视化工具。

- **[组合（Composition）](关于组合.md)** — 组合允许在同一进程中运行多个节点组件，从而减少通信开销并提高效率。

- **[交叉编译](关于交叉编译.md)** — 交叉编译允许在一个平台上构建 ROS 2 包，然后在另一个（通常是嵌入式）平台上运行。

- **[ROS 2 安全](关于安全.md)** — ROS 2 通过 DDS-Security 规范支持安全功能，包括身份验证、加密和访问控制。

- **[Tf2](关于Tf2.md)** — tf2 是坐标变换库，用于跟踪机器人各部件之间的空间关系，随时间管理坐标变换树。
