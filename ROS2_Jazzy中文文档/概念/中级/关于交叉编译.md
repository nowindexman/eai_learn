# 交叉编译

## 概述

Open Robotics 提供多个平台的预构建 ROS 2 包，但许多开发者仍依赖交叉编译，原因包括：
- 开发机与目标系统不匹配
- 针对特定 CPU 架构调优编译（如为树莓派 3 设置 `-mcpu=cortex-a53 -mfpu=neon-fp-armv8`）
- 目标文件系统不同于预构建镜像支持的

## 工作原理

交叉编译简单软件相对容易，只需使用交叉编译工具链。但以下因素使过程更复杂：

- 软件必须支持目标架构，架构特定代码需正确隔离
- 所有依赖项（如库）必须在交叉编译目标软件之前预先构建或交叉编译
- 使用构建工具（如 colcon）编译软件栈时，构建工具需提供机制允许开发者在底层构建系统上启用交叉编译

## 替代方案

交叉编译的替代方案是使用 `docker buildx` 构建多平台 Docker 镜像。
