# 关于发现

节点的发现是通过 ROS 2 底层中间件自动进行的。可以总结如下：

1. **当一个节点启动时**，它会向同一 ROS 域（通过 `ROS_DOMAIN_ID` 环境变量设置）中网络上的其他节点广播自己的存在。节点会响应此广播，提供关于自身的信息，以便建立适当的连接并进行通信。
2. **节点定期广播**其存在，即使在初始发现期之后，也能与新发现的实体建立连接。
3. **节点在离线时**会通知其他节点。

节点只有在具有兼容的[服务质量（QoS）](../中级/关于QoS.md)设置时才会与其他节点建立连接。

以 **talker-listener 演示**为例。在一个终端运行 C++ talker 节点在某个话题上发布消息，在另一个终端运行 Python listener 节点订阅同一话题上的消息。

您会看到这些节点自动发现彼此，并开始交换消息。
