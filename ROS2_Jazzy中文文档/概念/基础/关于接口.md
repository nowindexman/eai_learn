# 接口（Interfaces）

## 背景

ROS 应用通常通过三种接口类型之一通信：话题、服务或动作。ROS 2 使用简化的描述语言——接口定义语言（IDL）来描述这些接口，便于工具自动为多种目标语言生成源代码。

支持的类型：
- **msg**：`.msg` 文件描述 ROS 消息的字段
- **srv**：`.srv` 文件描述服务（请求 + 响应）
- **action**：`.action` 文件描述动作（目标 + 结果 + 反馈）

## 消息（Messages）

消息是 ROS 2 节点向网络发送数据的方式，不期望响应。

`.msg` 文件位于 ROS 包的 `msg/` 目录中，由两部分组成：字段和常量。

### 字段

每个字段由类型和名称组成：

```
int32 my_int
string my_string
```

### 字段类型

内置类型包括：

| 类型名 | C++ | Python | DDS |
|--------|-----|--------|-----|
| bool | bool | builtins.bool | boolean |
| byte | uint8_t | builtins.bytes | octet |
| float32 | float | builtins.float | float |
| float64 | double | builtins.float | double |
| int8/16/32/64 | intN_t | builtins.int | 对应类型 |
| uint8/16/32/64 | uintN_t | builtins.int | 对应类型 |
| string | std::string | builtins.str | string |
| wstring | std::u16string | builtins.str | wstring |

数组类型：
- 静态数组：`int32[5]`
- 无界动态数组：`int32[]`
- 有界动态数组：`int32[<=5]`
- 有界字符串：`string<=10`

### 字段命名

字段名必须是小写字母数字字符，用下划线分隔单词。必须以字母开头，不能以下划线结尾或连续两个下划线。

### 默认值

可以为任何字段设置默认值：

```
fieldtype fieldname fielddefaultvalue
```

例如：
```
uint8 x 42
float32 y 5.5
string greeting "hello"
bool is_valid true
```

## 常量

常量在 `.msg` 文件中定义，不会在传输中改变：

```
constanttype CONSTANTNAME=constantvalue
```

例如：
```
int32 X=123
int32 Y=-123
string FOO="hello"
bool EXAMPLE=true
```

## 服务（srv）

`.srv` 文件位于 `srv/` 目录，由请求和响应组成，用 `---` 分隔：

```
# 请求
int64 a
int64 b
---
# 响应
int64 sum
```

## 动作（action）

`.action` 文件位于 `action/` 目录，由目标、结果和反馈三部分组成：

```
# 目标
int32 order
---
# 结果
int32[] sequence
---
# 反馈
int32[] sequence
```
