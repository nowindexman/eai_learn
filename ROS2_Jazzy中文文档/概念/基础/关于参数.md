# 关于参数

## 概述

ROS 2 中的参数与各个节点相关联。参数用于在启动时（以及运行时）配置节点，而无需修改代码。参数的生命周期与节点的生命周期绑定（尽管节点可以实现某种持久化机制以在重启后重新加载值）。

参数通过节点名称、节点命名空间、参数名称和参数命名空间来寻址。参数命名空间是可选的。

每个参数由一个**键（key）**、一个**值（value）**和一个**描述符（descriptor）**组成。键是字符串，值是以下类型之一：`bool`、`int64`、`float64`、`string`、`byte[]`、`bool[]`、`int64[]`、`float64[]` 或 `string[]`。默认情况下所有描述符为空，但可以包含参数描述、值范围、类型信息和附加约束。

## 参数背景

### 声明参数

默认情况下，节点需要**声明（declare）**它在生命周期内将接受的所有参数。这样做的目的是在节点启动时明确参数的类型和名称，减少后续配置错误的可能性。

对于某些类型的节点，并非所有参数都能提前知道。在这些情况下，可以将节点的 `allow_undeclared_parameters` 设置为 `true`，允许在节点上获取和设置尚未声明的参数。

### 参数类型

ROS 2 节点上的每个参数都有预定义的参数类型之一。默认情况下，在运行时更改已声明参数的类型的尝试将失败，这可以防止常见错误（例如将布尔值放入整数参数）。

如果参数需要支持多种不同类型，并且使用该参数的代码能处理，可以在声明参数时将 `ParameterDescriptor` 的 `dynamic_typing` 成员变量设置为 `true`。

### 参数回调

ROS 2 节点可以注册三种不同类型的回调来获知参数的变化。这三种回调都是可选的：

1. **"预设置参数"回调（Pre-set parameter callback）**：通过 `add_pre_set_parameters_callback` 设置。接收正在更改的 `Parameter` 对象列表，不返回值。可以在调用时修改参数列表、添加或移除条目。

2. **"设置参数"回调（Set parameter callback）**：通过 `add_on_set_parameters_callback` 设置。接收不可变的 `Parameter` 对象列表，返回 `SetParametersResult`。主要用于检查即将到来的参数更改并明确拒绝更改。

   > **注意**：重要的是"设置参数"回调不应有副作用。因为多个回调可以链式调用，单个回调无法知道后续回调是否会拒绝更新。

3. **"后设置参数"回调（Post-set parameter callback）**：通过 `add_post_set_parameters_callback` 设置。接收不可变的 `Parameter` 对象列表，不返回值。主要用于对已成功接受的参数更改做出响应。

## 与参数交互

ROS 2 节点可以通过节点 API 执行参数操作。外部进程可以通过节点实例化时默认创建的参数服务执行参数操作。默认创建的服务包括：

| 服务 | 类型 | 功能 |
|---|---|---|
| `/node_name/describe_parameters` | `DescribeParameters` | 返回参数描述符列表 |
| `/node_name/get_parameter_types` | `GetParameterTypes` | 返回参数类型列表 |
| `/node_name/get_parameters` | `GetParameters` | 返回参数值列表 |
| `/node_name/list_parameters` | `ListParameters` | 列出可用参数 |
| `/node_name/set_parameters` | `SetParameters` | 设置参数（逐个） |
| `/node_name/set_parameters_atomically` | `SetParametersAtomically` | 原子设置参数 |

## 在运行节点时设置初始参数值

可以通过单独的命令行参数或 YAML 文件在运行节点时设置初始参数值。

## 在使用 launch 启动节点时设置初始参数值

也可以通过 ROS 2 的 launch 设施在运行节点时设置初始参数值。

## 在运行时操作参数值

`ros2 param` 命令是与正在运行的节点参数交互的通用方式。`ros2 param` 使用上述参数服务 API 执行各种操作。

此外，还可以在运行时使用 ROS 2 客户端库以编程方式操作参数。所有客户端库都提供了在节点运行时获取、设置和响应参数变化的 API。

## 从 ROS 1 迁移

Launch 文件迁移指南解释了如何将 `param` 和 `rosparam` launch 标签从 ROS 1 迁移到 ROS 2。迁移指南还解释了参数从 ROS 1 到 ROS 2 的迁移方法。
