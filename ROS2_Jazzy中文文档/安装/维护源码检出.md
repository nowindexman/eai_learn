# 维护源码检出

如果从源码安装了 ROS 2，自检出以来源代码可能已有更改。要保持源码检出最新，需要定期更新 ``ros2.repos`` 文件、下载最新源码并重建工作区。

## 更新仓库列表

每个 ROS 2 发行版包含一个 ``ros2.repos`` 文件，列出了该发行版的所有仓库及其版本。

### 最新的 ROS 2 Jazzy 分支

```console
# Linux/macOS
$ cd ~/ros2_jazzy
$ mv -i ros2.repos ros2.repos.old
$ wget https://raw.githubusercontent.com/ros2/ros2/jazzy/ros2.repos

# Windows（命令提示符）
$ cd \dev\ros2_jazzy
$ curl -sk https://raw.githubusercontent.com/ros2/ros2/jazzy/ros2.repos -o ros2.repos

# Windows（PowerShell）
$ cd \dev\ros2_jazzy
$ curl https://raw.githubusercontent.com/ros2/ros2/jazzy/ros2.repos -o ros2.repos
```

## 更新仓库

`ros2.repos <https://raw.githubusercontent.com/ros2/ros2/jazzy/ros2.repos>`__ 文件中每个仓库都有 ``version`` 指向特定的提交哈希、标签或分支名。应先更新已检出的仓库：

```console
$ vcs custom --args remote update
```

## 下载新源码

```console
# Linux/macOS
$ vcs import src < ros2.repos
$ vcs pull src

# Windows
$ vcs import --input ros2.repos src
$ vcs pull src
```

## 重建工作区

工作区已更新到最新源码后，删除之前的安装并重建：

```console
$ colcon build --symlink-install
```

## 检查源码检出状态

在开发过程中可能偏离了导入仓库列表时的原始状态。可以导出仓库信息：

```console
# Linux/macOS
$ cd ~/ros2_jazzy
$ vcs export src > my_ros2.repos

# Windows
$ cd \dev\ros2_jazzy
$ vcs export src > my_ros2.repos
```

此 ``my_ros2.repos`` 文件可以分享给他人，以便重现工作区中仓库的状态。
