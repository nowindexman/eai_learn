# Makoa Mata-mata Release Timeline

For progress on the development of Makoa Mata-mata, see [this project board ](https://github.com/orgs/ros2/projects/80)_.
For the broad process followed by Makoa Mata-mata, see the [process description page ](../Release-Process).

**Friday May 21st, 2027** - General Availability
    * Release announcement.
    * ROS desktop packages source freeze is lifted and ``rosdistro`` is reopened for Makoa pull requests.

**December, 2028** - End-of-life
    * ROS Makoa will stop receiving updates - including security updates
