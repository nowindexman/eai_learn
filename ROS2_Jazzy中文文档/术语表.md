# 术语表

本文档中使用的术语汇编：

## API

API，即应用程序编程接口（Application Programming Interface），是由"应用程序"提供的接口，在这种情况下通常是共享库或其他语言适当的共享资源。API 由定义使用接口的软件和提供接口的软件之间契约的文件组成。这些文件通常表现为 C/C++ 中的头文件和 Python 中的 Python 文件。在任何情况下，API 都应该在文档中分组描述，并声明为公共或私有。公共接口受更改规则约束，对公共接口的更改会触发提供它们的软件的新版本号。

## 客户端库（Client Library）

客户端库是一个 [API](#api)，它使用话题（Topics）、服务（Services）和动作（Actions）等基本中间件概念提供对 ROS 图的访问。

## 包（Package）

软件的最小单元，包括源代码、构建系统文件、文档、测试和其他相关资源。

## REP

机器人增强提案（Robotics Enhancement Proposal）。描述 ROS 社区增强、标准化或规范的文档。相关的 REP 审批流程允许社区对提案进行迭代，直到达成共识，之后可以被批准并实施，然后成为文档。所有 REP 可在 [REP 索引](https://reps.openrobotics.org/) 中查看。

## VCS

版本控制系统（Version Control System），如 CVS、SVN、git、mercurial 等。

## rclcpp

ROS 的 C++ [客户端库](#客户端库client-library)。包括任何中间件相关的 API，以及基于消息、服务和动作等接口定义生成 C++ 数据结构的相關消息生成。

## 仓库（Repository）

通常使用 [VCS](#vcs)（如 git 或 mercurial）管理的包的集合，通常托管在 GitHub 或 BitBucket 等站点上。在本文档的上下文中，仓库通常包含一个或多个某种类型的[包](#包package)。
