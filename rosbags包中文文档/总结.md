## 一、项目概览

**Rosbags** 是一个纯 Python 库，用于处理一切与 rosbag（ROS bag 文件）相关的操作。它的核心特点：

- **纯 Python 实现**：不依赖任何 ROS 软件栈（ROS1 / ROS2），可独立使用
- **统一接口**：提供高层 API（AnyReader），可透明地读取 ROS1 和 ROS2 bag 文件
- **可扩展类型系统**：内置 `.idl` / `.msg` 解析器，支持运行时动态注册自定义消息类型
- **高效转换**：rosbag1 ↔ rosbag2 格式转换采用原始字节流直接转换，无需中间反序列化
- **全面支持**：覆盖 ROS2 版本至 Jazzy（v9），存储格式支持 sqlite3 和 mcap

**安装**：`pip install rosbags`

### 2. [topics/highlevel.md](topics/highlevel.md) — 高级接口

| 项目 | 内容 |
|------|------|
| **主题** | `rosbags.highlevel` 包 — AnyReader 统一读取器 |
| **核心类** | `AnyReader` — 可同时读取一组 ROS1 或 ROS2 bag 文件（不能混合格式） |
| **关键特性** | 自动按时间戳排序回放消息；自动注册所有消息类型定义到内部 TypeStore |
| **使用场景** | 最常用的 bag 文件读取方式，无需关心底层格式差异 |
| **进阶用法** | 对缺少消息定义的旧版 ROS2 bag，可通过 `default_typestore` 参数手动指定 |
| **原文地址** | https://ternaris.gitlab.io/rosbags/topics/highlevel.html |

**核心代码模式**：
```python
with AnyReader([Path('path/to/bag')]) as reader:
    connections = [x for x in reader.connections if x.topic == '/imu_raw/Imu']
    for connection, timestamp, rawdata in reader.messages(connections=connections):
        msg = reader.deserialize(rawdata, connection.msgtype)
```

### 3. [topics/typesys.md](topics/typesys.md) — 类型系统

| 项目 | 内容 |
|------|------|
| **主题** | `rosbags.typesys` — Rosbags 的纯 Python 类型系统 |
| **核心概念** | TypeStore（类型存储）— 消息定义的仓库，管理序列化/反序列化函数 |
| **获取方式** | `get_typestore(Stores.ROS2_HUMBLE)` 通过 `Stores` 枚举指定 ROS 发行版 |
| **支持的存储** | empty、ros1_noetic、ros2_dashing ~ ros2_kilted（共 10 个） |
| **序列化** | `.serialize_cdr()` / `.serialize_ros1()` |
| **反序列化** | `.deserialize_cdr()` / `.deserialize_ros1()` |
| **消息实例** | 类型系统为每个消息类型生成 dataclass，通过 `typestore.types[typename]` 访问 |
| **自定义类型** | 使用 `get_types_from_idl()` / `get_types_from_msg()` 解析定义，再 `typestore.register()` 注册 |
| **原文地址** | https://ternaris.gitlab.io/rosbags/topics/typesys.html |

**支持的 ROS 发行版（Stores 枚举）**：

| 枚举值 | 对应版本 |
|--------|----------|
| `Stores.EMPTY` | 空存储（仅含基础时间类型） |
| `Stores.ROS1_NOETIC` | ROS1 Noetic |
| `Stores.ROS2_DASHING` | ROS2 Dashing |
| `Stores.ROS2_ELOQUENT` | ROS2 Eloquent |
| `Stores.ROS2_FOXY` | ROS2 Foxy |
| `Stores.ROS2_GALACTIC` | ROS2 Galactic |
| `Stores.ROS2_HUMBLE` | ROS2 Humble |
| `Stores.ROS2_IRON` | ROS2 Iron |
| `Stores.ROS2_JAZZY` | ROS2 Jazzy |
| `Stores.ROS2_KILTED` | ROS2 Kilted |
| `Stores.LATEST` | 最新版本 |

## 七、关键 API 速查

### TypeStore（类型存储）

```python
from rosbags.typesys import Stores, get_typestore

typestore = get_typestore(Stores.ROS2_HUMBLE)

# 序列化
cdr_bytes = typestore.serialize_cdr(msg, 'std_msgs/msg/String')
ros1_bytes = typestore.serialize_ros1(msg, 'std_msgs/msg/String')

# 反序列化
msg = typestore.deserialize_cdr(rawdata, 'std_msgs/msg/String')
msg = typestore.deserialize_ros1(rawdata, 'std_msgs/msg/String')

# 注册自定义类型
from rosbags.typesys import get_types_from_msg
typestore.register(get_types_from_msg(definition_str, 'my_msgs/msg/MyType'))

# 获取消息类
MyType = typestore.types['my_msgs/msg/MyType']
```

### AnyReader（统一读取器）

```python
from pathlib import Path
from rosbags.highlevel import AnyReader

with AnyReader([Path('path/to/bag')]) as reader:
    # 元数据
    reader.duration        # bag 时长
    reader.start_time      # 起始时间戳
    reader.end_time        # 结束时间戳
    reader.message_count   # 消息总数
    reader.topics          # 话题信息

    # 遍历消息
    for conn, timestamp, rawdata in reader.messages():
        msg = reader.deserialize(rawdata, conn.msgtype)
```

### Reader / Writer（底层读写器）

```python
from rosbags.rosbag2 import Reader, Writer

# 读取
with Reader('path/to/bag') as reader:
    for conn, ts, data in reader.messages(connections=[...]):
        msg = typestore.deserialize_cdr(data, conn.msgtype)

# 写入
with Writer('path/to/output') as writer:
    conn = writer.add_connection('/topic', 'std_msgs/msg/String', typestore=typestore)
    writer.write(conn, timestamp, typestore.serialize_cdr(msg, msg.__msgtype__))
```
